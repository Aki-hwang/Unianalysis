# 홈페이지 기술 점검 요청서 (웹 담당 업체 전달용)

아래 내용을 홈페이지 관리 업체에 그대로 전달하시면 됩니다. AI 검색(ChatGPT, 퍼플렉시티 등)에서 병원이 인용되기 위한 기술 기반 작업입니다.

---

안녕하세요, 유앤아이의원 김포점(gpuni114.co.kr)입니다. AI 검색 노출 개선을 위해 아래 3가지 작업을 요청드립니다.

## 1. AI 크롤러 차단 여부 확인 및 허용 (가장 중요)

자동화 도구로 접속 시 사이트가 403을 반환하는 정황이 있습니다. 방화벽(WAF)이나 robots.txt에서 아래 AI 검색 크롤러들이 차단되어 있는지 확인하고, 차단되어 있다면 허용해 주세요. **차단 상태면 ChatGPT가 우리 사이트를 아예 읽지 못해 어떤 콘텐츠를 올려도 인용되지 않습니다.**

robots.txt에 아래 항목이 허용(Allow) 상태여야 합니다:

```
User-agent: GPTBot
Allow: /

User-agent: OAI-SearchBot
Allow: /

User-agent: ChatGPT-User
Allow: /

User-agent: ClaudeBot
Allow: /

User-agent: PerplexityBot
Allow: /

User-agent: Google-Extended
Allow: /
```

또한 서버/WAF(클라우드플레어 등) 설정에서 위 User-Agent에 대한 봇 차단 룰이 있다면 예외 처리해 주세요.

## 2. 병원 정보 구조화 데이터(JSON-LD) 추가

모든 페이지의 `<head>`에 아래 스크립트를 추가해 주세요. 검색엔진과 AI가 병원 정보를 정확히 파악하게 하는 표준 마크업입니다. **진료시간(openingHoursSpecification)은 실제 시간표로 수정 후 적용해 주세요.**

  "address": {
    "@type": "PostalAddress",
    "streetAddress": "김포한강4로 525 감두리빌딩 2층",
    "addressLocality": "김포시",
    "addressRegion": "경기도",
    "postalCode": "10099",
    "addressCountry": "KR"
  },
  "geo": { "@type": "GeoCoordinates", "latitude": 37.6659, "longitude": 126.6293 },
  "medicalSpecialty": "Dermatology",
  "availableService": [
    { "@type": "MedicalProcedure", "name": "울쎄라 리프팅" },

    { "@type": "MedicalProcedure", "name": "스킨부스터" },
    { "@type": "MedicalProcedure", "name": "레이저 제모" },
    { "@type": "MedicalProcedure", "name": "색소 치료" }

## 3. 시술 페이지에 FAQ 구조화 데이터 추가

울쎄라, 보톡스 등 주요 시술 페이지에 실제 페이지 내 Q&A 내용과 일치하는 FAQPage 마크업을 추가해 주세요. 형식 예시:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "울쎄라 시술 시간은 얼마나 걸리나요?",
      "acceptedAnswer": { "@type": "Answer", "text": "부위와 샷 수에 따라 다르지만 보통 30분에서 1시간 정도 소요됩니다." }
    },
    {
      "@type": "Question",
      "name": "울쎄라 시술 후 일상생활이 가능한가요?",
      "acceptedAnswer": { "@type": "Answer", "text": "대부분 시술 직후 일상 복귀가 가능합니다. 일시적인 붉어짐이나 부기가 있을 수 있으며 개인차가 있습니다." }
    }
  ]
}
</script>
```
