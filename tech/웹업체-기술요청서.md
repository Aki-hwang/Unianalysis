## ⚠️ 요청 0. og:description의 "일요일진료" 즉시 수정 (가장 급함)

메인 페이지 `<head>`의 og:description에 아래 문구가 **현재 라이브로** 실려 있습니다:

```
예뻐지는시간, 유앤아이의원 김포점ㅣ김포피부과,구래역피부과,김포보톡스,김포필러,김포제모,
김포리프팅,김포여드름,김포울쎄라,김포써마지,야간/일요일진료
```

**일요일은 휴진**인데 "일요일진료"로 표기되어 있고, 이 문구가 검색 결과와 AI 답변에 그대로 인용되는 것이 확인됐습니다(카카오톡 공유 미리보기에도 노출). 일요일 헛걸음 민원으로 직결되는 문제입니다.

- **수정 요청**: `야간/일요일진료` → `야간진료`
- `<meta name="description">` 태그도 함께 점검 부탁드립니다
- 본문에는 이 문자열이 없어 수정은 한 줄입니다

- **문제 ②: 메인에 병원 정보(MedicalClinic) 구조화 데이터 없음** (캐러셀 ItemList만 존재)

## 요청 1. 메인 페이지 경량화 (가장 중요)

메인 HTML이 2.4MB입니다. AI 검색 봇들은 대체로 1MB 안팎에서 읽기를 포기하므로 **1MB 이하**를 목표로 줄여 주세요.

- 이미지 지연 로딩(lazy loading) 적용, 첫 화면 외 섹션의 마크업 축소
- 사용하지 않는 인라인 스크립트·스타일·중복 마크업 정리
- 가능하면 시술 소개는 "요약 + 개별 페이지 링크" 구조로 분리

## 요청 2. 메인 head에 병원 정보 구조화 데이터(JSON-LD) 추가

현재 캐러셀(ItemList)만 있습니다. 아래 MedicalClinic 스키마를 추가해 주세요. **진료시간·좌표는 실제 값으로 교체 후 적용.**

```html

{
  "@context": "https://schema.org",
  "@type": "MedicalClinic",
  "name": "유앤아이의원 김포점",
  "url": "https://www.gpuni114.co.kr/",
  "telephone": "+82-31-8049-6024",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "김포한강4로 525 감두리빌딩 2층",
    "addressLocality": "김포시",
    "addressRegion": "경기도",
    "addressCountry": "KR"
  },
  "medicalSpecialty": "Dermatology",
  "availableService": [
    { "@type": "MedicalProcedure", "name": "울쎄라 리프팅" },
    { "@type": "MedicalProcedure", "name": "써마지" },
    { "@type": "MedicalProcedure", "name": "올리지오" },
    { "@type": "MedicalProcedure", "name": "보톡스" },
    { "@type": "MedicalProcedure", "name": "필러" },
    { "@type": "MedicalProcedure", "name": "레이저 제모" }
  ]
}
</script>
```

※ 일요일은 휴진이므로 openingHoursSpecification을 넣을 경우 Sunday 항목을 넣지 마세요.
