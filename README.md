# Unianalysis — 유앤아이의원 김포점 AI 검색 노출 분석

ChatGPT 등 AI 검색에서 유앤아이의원 김포점이 얼마나 노출되는지 측정한 리포트입니다.

- **리포트 페이지**: [`index.html`](index.html) — 브라우저로 열면 대시보드 형태로 볼 수 있습니다.
- **측정 방식**: 잠재 고객이 물어볼 법한 11개 질문(예: "김포 피부과 추천", "김포 울쎄라 잘하는 곳")으로 웹 검색을 실행하고, AI 답변이 인용하는 상위 소스에 병원이 등장하는지 확인.
- **최근 측정일**: 2026-07-24 · 종합 노출률 23% (11개 중 노출 2, 부분 1, 미노출 8)

## 다음 측정 방법

1. `index.html`의 "직접 재테스트하는 법" 섹션의 질문 10개를 ChatGPT(웹 검색 켠 상태)에 붙여 넣는다.
2. 유앤아이 김포점이 언급된 질문 수를 센다.
3. 노출률(언급 수 ÷ 10)을 이전 측정과 비교한다.
