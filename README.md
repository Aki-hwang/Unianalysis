# Unianalysis — 유앤아이의원 김포점 AI 검색 워크스페이스

ChatGPT·Gemini·Perplexity·Grok·구글 AIO·네이버에서 유앤아이의원 김포점이 얼마나 노출되는지 추적하는 노션 스타일 워크스페이스입니다.

- **워크스페이스**: [`index.html`](index.html) — 트래킹 보드(질의어 × AI × 날짜 도트 매트릭스), 기준 측정 결과, 진단, 실행 플랜(체크리스트), 키워드 테스트 도구, 콘텐츠 자료.
- **키워드 테스트**: 키워드 입력 → 각 AI에 질문이 입력된 링크 자동 생성 → 결과(노출/부분/미노출) 기록 → 보드에 점 표시. 기록은 브라우저(localStorage)에 저장되고 CSV로 내려받을 수 있습니다.
- **기준 측정**: 2026-07-24 웹 검색 기반, 11개 키워드 중 노출 2 · 부분 1 · 미노출 8 (노출률 23%). 매달 1일 자동 재측정.

## 폴더 구성

- `content/` — 블로그 원고 3편(울쎄라·동네 키워드·일요일 진료), 리뷰 요청 템플릿
- `tech/` — 웹 담당 업체 전달용 기술 요청서 (AI 크롤러 허용 + JSON-LD 구조화 데이터)
